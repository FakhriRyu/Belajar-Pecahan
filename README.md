# 🍕 Pecahan Ajaib - Media Belajar Pecahan Senilai Interaktif

Aplikasi web edukasi interaktif untuk membantu anak-anak memahami konsep **Pecahan Senilai** secara visual, menyenangkan, dan intuitif dengan gaya visual kartun 3D yang ceria (Duolingo & Toca Boca aesthetic).

---

## ✨ Fitur Utama

- 🗺️ **Peta Jalur Tingkat (8 Level Tantangan)**: Alur progres belajar berjenjang dengan sistem bintang emas dan hadiah trofi.
- 🧪 **Lab Timbangan & Eksplorasi Interaktif**: Eksplorasi bebas membandingkan dua pecahan secara visual melalui Pizza, Balok Cokelat, dan Gelas Ukur Ramuan Ajaib dengan timbangan seimbang dan fitur overlay transparansi.
- 🏪 **Kedai Pizza Senilai**: Mini-game melayani pesanan pizza pelanggan hewan lucu dengan membagi loyang sesuai pecahan senilai yang diminta.
- 🏆 **Ruang Trofi & Pencapaian**: Koleksi lencana (*badges*), penghitung bintang ⭐, dan koin emas 🪙 yang diraih.
- 🐱 **Maskot Kibo si Kucing Koki**: Pendamping belajar ceria dengan animasi dan efek suara sintetis web audio.
- 🌐 **Dua Bahasa (Bilingual)**: Mendukung Bahasa Indonesia dan English.

---

## 🛠️ Teknologi yang Digunakan

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS (3D Toy Neumorphic / Chunky aesthetic)
- **Icons**: Lucide React
- **Audio**: Web Audio API Sound Synthesizer (Zero external audio assets needed)
- **Effects**: Canvas Confetti

---

## 🚀 Menjalankan Secara Lokal

1. **Clone repositori**:
   ```bash
   git clone https://github.com/FakhriRyu/Belajar-Pecahan.git
   cd Belajar-Pecahan
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Jalankan dev server**:
   ```bash
   npm run dev
   ```

4. **Build untuk produksi**:
   ```bash
   npm run build
   npm run preview
   ```
